# P16.36 — Coroutine yield/resume path: frame-scan inventory (post Cut 3)

Status after Cut 3 (gsub scan → nCcalls nny unit). This is an HONEST
enumeration of the frame scans that REMAIN in the yield/resume path —
Cut 3 removed ONE scan (`hasActiveBytecodeNonYieldableBoundary`); it does
NOT claim "all scans removed".

## Hot path (per yield / per resume)

| Scan | Site (vm.zig) | Cost | Why it remains |
|---|---|---|---|
| Topmost-Lua-frame search (suspension owner) | `builtinCoroutineYield` P15.79 path (~line 21729): walks down past C-frames from `len()-1` to find the Lua frame to park in-place | O(#C-frames above the owner), typically 1–2 steps | PUC `lua_yieldk` writes the continuation (`ci->u.c.k`) on the TOP C CallInfo — O(1) because CallInfo is a linked list and the top frame IS the C frame. luazig's frame array + hidden synthetic C-frames mean the owner must be located; removing this needs a "suspension owner index" or a C-frame-top invariant (candidate: cache `lua_frame_index` on Thread at C-frame push/pop, mirroring `hook_frame_index` from P15.51n). |
| C-frame presence check | `coroutineBuiltinFastPathEligible` | O(1) — `Thread.c_frame_count` (P16.26 D) | already O(1), listed for completeness |
| Yieldability check | `builtinCoroutineYield` / `isyieldable` / fast-path eligibility | O(1) — `Thread.yieldable()` (nCcalls upper bits; this cut) | done |

## Resume path

| Scan | Site | Cost | Why it remains |
|---|---|---|---|
| Topmost-frame dispatch | `builtinCoroutineResume` / `finishCcall` region: reads `len()-1` only | O(1) | not a scan |
| testC continuation frames | `finishCcall` (C-frame `u.c.k` continuation machinery) | O(1) per frame pop; the C-frame is located at the top | PUC `unroll`/`finishCcall` parity — the continuation lives ON the C-frame, no search |
| Unwind/pop loops | close + error-unwind `while (call_frames.len() > target)` loops (~21996, 22053, 22114, 22323) | O(frames being popped) | structural unwind, not a lookup — each popped frame does real work (closers, pending cancels, upvalue closes); cannot be O(1) |

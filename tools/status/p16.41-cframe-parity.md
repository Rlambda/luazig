## PUC ground truth (lua-5.5.0/src, verified)

- `lua_getstack` (ldebug.c:162): level 0 = `L->ci` (CURRENT CallInfo — the running
  debug builtin's own C frame), walk `previous` down; `base_ci` excluded.
- `getfuncname` (ldebug.c:323): name of the function in `ci` comes from
  `funcnamefromcall(ci->previous)` — the CALL SITE in the caller. C caller → NULL
  → `namewhat=""`, `name=nil` (auxgetinfo ldebug.c:369-375).
- `funcnamefromcall` (ldebug.c:659): CIST_HOOKED → "hook"/"?"; CIST_FIN →
  "metamethod"/"__gc"; Lua → funcnamefromcode; C → NULL.
- Every builtin IS a C function in PUC → real visible CallInfo (pcall, sort,
  getinfo, print, ...). `lua.c` entry: `main → lua_pcall(pmain)` → exactly ONE
  C frame (`pmain`) below the script chunk (file mode, `-e`, REPL line — all
  verified: getinfo(2) from main = `C` nameless; traceback ends `[C]: in ?`).
- Coroutine bodies: `lua_resume` → NO C frame below the body (base_ci directly).

Fixes landed during the cut (beyond the frame-visibility core):

1. **CIST_FIN (PUC lgc.c GCTM)**: bit 24 was defined but never set.
   `callFinalizer` now flags the active thread's top frame around
   `callMetamethod` (function-scoped defer via `fin_caller_idx` — a `defer`
   inside the guarding `if` block is block-scoped and ran too early).
   getinfo `.frame` checks `parent_frame.isFin()` BEFORE `getDebugName`
   (PUC funcnamefromcall order: CIST_HOOKED → CIST_FIN → funcnamefromcode);
   `getFuncNameForFrame` checks `parent.isFin()` before the proto() gate.
   This fixed the db.lua finalizer test hang (db.lua:913-930: getinfo(1)
   inside __gc returned nil name → `repeat local a = {} until name` looped).

2. **'n' option gating (PUC auxgetinfo)**: name/namewhat setFields were set
   unconditionally; PUC sets them only when 'n' is in `what` (or what empty).
   Gated in .phantom, .virtual_yield, the whole .frame chain, and the
   .Builtin/.Closure path.

3. **Sync C-hook yield (PUC lua_yieldk hook branch + luaG_traceexec)**:
   `DebugHookState.sync_hook_frame_idx` records the interrupted frame in
   `debugDispatchHookTransfer`'s c_hook path; `builtinCoroutineYield`'s new
   sync branch pops everything above that frame, clears
   `suspended_builtin`/`suspended_builtin_args` (PUC: no hook frame, no
   yield CallInfo), and sets `bytecode_inplace_suspended` +
   `bytecode_resume_boundary` so the interrupted frame survives the unwind.
   The ASYNC hook-yield branch got the same `suspended_builtin` clearing
   (it popped the frames but left the virtual yield frame in the item
   model). Fixed coroutine.lua:699 (testC "yield 0" line hook: level 0 =
   interrupted Lua frame, level 1 = nil, no [C] lines in traceback).

4. **C-temporary window (PUC luaG_findlocal)**: new `suspendedCWindow`
   helper — the suspended top C frame's observable window is its parked
   stack (testC script frame / continuation frames) minus the top
   `aux.nyield` values that auxresume moved to the resumer; plain builtin
   yields (coroutine.yield) have an empty window (all args moved).
   T.testC("yield 1", 10, 20) → getlocal(co, 0, 2) == "(C temporary)", 10
   (coroutine.lua:722).

5. **luaL_where level (PUC lauxlib.c)**: `luaL_error`/`luaL_argerror` used
   `luaL_where(L, 0)` — a pre-Cut-1 compensation for invisible C frames
   (stale comment said so explicitly). Restored PUC's `luaL_where(L, 1)`.
   This was a REAL regression caught by c_api 23_tbc_semantics diff
   (k_cont_error's "cont-err" lost its "[string ...]:1:" prefix); HEAD was
   byte-identical, the cut had broken it, now identical again.
